# 战斗、物品、武功

这些改动只出现在 kdef 里。物品表和武功表在 `ranger`；战斗表在 `resource/War.sta`。不要为了一场剧情去改角色初始属性，除非这段剧情就是“永久学会/永久增减”。

## 战斗

opcode 6：`战斗(battleId, 胜跳转, 负跳转, 是否得经验)`。

- `battleId` 是 `War.sta` 下标，不是场景号。
- 两个跳转是相对位移，胜负走不同分支。后面的发奖、改 DData 放在对应分支里。
- `getExp` 非 0 时走战后经验和升级。剧情战若不要经验，传 0。
- 胜负之后用 opcode 3 关掉原触发（脚本槽改 0 或换成下一段），避免同一格重复开战。

## 物品

| opcode | 作用 | 何时用 |
|--------|------|--------|
| 2 | 增减物品并提示 | 玩家看得到的奖励或没收 |
| 32 | 静默增减 | 剧情道具计数，不要弹获得框 |
| 18 | 判断数量并跳转 | 已经拥有则跳过发放 |
| 4 | 判断是否持有并跳转 | 二选一分支 |
| 41 | 写角色随身格 | 装备在身上，不是进背包 |

数量为负表示失去。先判断再发放，避免重复触发刷物品。

## 武功

| opcode | 参数含义 |
|--------|----------|
| 33 | 角色、武功号、熟练度。会提示“学会” |
| 34 | 角色、资质增量 |
| 35 | 角色、武功栏位、武功号、熟练度。指定栏，不弹普通学会句时要按现有脚本习惯 |
| 45–48 | 轻功、内力上限、攻击、生命上限 |
| 49 | 内力属性 |

武功号来自 ranger 的 magic 表。栏位是 0–9。已经学会就不要再 opcode 33；用 18/4 式的分支，或先查同场景旧脚本怎么跳过。

改属性用 45–48 的增量，不要直接改 `ranger` 初始记录，否则新游戏开局就会带上这段奖励。
