# 对白

正文用简体写入编辑器，落盘为 GBK（`TalkArchive`，XOR 0xFF）。不要把 UTF-8 直接写进 `talk.grp`。

## 控制符

| 写法 | 作用 |
|------|------|
| `**` | 换行 |
| `&&` | 主角全名 |
| `$$` | 主角姓 |
| `%%` | 主角名 |
| `@0` | 主角全名（旧式） |
| `@N` | 主角外号 |
| `@@` | 停顿，不显示 |
| `##` | 短延迟，不显示 |
| `^` 加一位 | 颜色，不显示 |

玩家名永远用控制符，不要写死“软体娃娃”或某次建角的名字。

## 口吻

从现有 `talk` 归纳，新对白要靠近这些特征：

- 一句一事，少用现代词。短句堆叠，靠 `**` 断句，不写长段说明。
- 武林称谓：在下、公子、姑娘、帮主、师父。自报姓名时常带门派或外号。
- 戏谑可以有，但是江湖玩笑，不是网络口语。反派可以轻佻，正派说话留半句余地。
- 主角被称呼时用 `$$` 或 `&&`，旁白不代替主角做长篇独白。
- 系统提示（学会武功、品德、声望）保持引擎原句，不要在 talk 里再写一遍。

opcode 1 是 `对话(talk编号, 头像, 模式)`。头像用人物 HeadNum；旁白头像用约定值，不要发明新的模式号。opcode 68 是带姓名编号的新对话，用于需要显式说话人的长段。

范例：

```
$$兄，**在下挡了你的路。**这坛酒，还请收下。
```
