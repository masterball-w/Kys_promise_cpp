# 剧情与地图

坐标轴与引擎一致：DData[10] = X，DData[9] = Y。SData `get(scene, layer, x, y)` 用同一套轴。制作器俯视图横轴是 Y、纵轴是 X，写文件时不要跟着画面轴走。

## 层

| SData 层 | 内容 |
|----------|------|
| 0–2 | 地面与建筑，剧情一般不改 |
| 3 | 事件号。`-1` 为空。必须等于要触发的 DData 事件号 |
| 4–5 | 不要拿来挂脚本 |

人物贴图在 DData[5]/[6]/[7]（当前 / 结束 / 起始），是偶数贴图码（`code/2` 为 smp 或 mmap 索引）。换姿势用 opcode 3 或 38，把三格一起写成目标码。开场模板例子：场景 0 事件 0 为 8284，事件 1 为 8268，坐标在卧室内。

## 触发必须同时满足

1. 层 3 在角色所站或所面对的格子上有事件号。
2. 该事件 DData 的 X/Y 与这个格子相同。错一位就不会画在触发点上。
3. 对应脚本槽 > 0，且 kdef 里真有该编号。
4. 贴图码为 0 的事件可能不绘制；踩上脚本仍看层 3，不要只改贴图不改层 3。

opcode 3（ModifyEvent）参数会写回 DData。脚本号在 DData[2..4]。用它推进剧情：第一段把踩上脚本改成 0、手动脚本改成下一段，或把贴图从起始码改成结束码。

opcode 17 写的是 SData 格子，不是 DData。改“这格是不是事件”用 17 或直接改层 3；改“这个事件说什么、进哪场战斗”改 kdef。

## 场景切换

- 室内换幕：opcode 71 `JmpScene`，或 opcode 19 瞬移。
- 大地图入口：ranger 场景记录的 MainEntranceX/Y（字 11/10 与 13/12）。这只决定从世界地图进入场景，不代替层 3。
- opcode 39 开放场景后，入口才应可见。不要先把入口坐标改到新场景却不开放场景。

## 核对

`inspect_story.py` 会列出：DData 十一字、三个脚本槽、层 3 上所有等于该事件号的格子，以及脚本里出现的 talk 编号。层 3 格子与 DData 的 X/Y 不一致时，脚本会报 `MISMATCH`。
