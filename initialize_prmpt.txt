# KYS Promise C++ 重构项目 - 开发进度总结

## 项目概述

这是一个将经典DOS游戏《金庸群侠传》从Pascal/Lazarus源码重构为现代C++的项目。目标是保持与原版游戏数据文件的二进制兼容性，同时提供更好的代码结构和可维护性。

## 技术架构

### 核心架构
- **语言**: C++17
- **图形库**: SDL3 + SDL3_ttf + SDL3_image
- **构建系统**: CMake
- **平台**: Windows

### 类层次结构
```
GameObject (基类，处理序列化)
├── Role (角色数据，91个int16_t字段)
├── Item (物品数据，95个int16_t字段)
├── Magic (武学数据)
└── Scene (场景数据)

GameManager (单例，管理全局状态)
├── GraphicsUtils (图形渲染)
├── BattleManager (战斗系统)
├── EventManager (事件系统)
└── UIManager (UI系统)
```

### 关键文件位置
- `cpp_reborn/include/` - 头文件
- `cpp_reborn/src/` - 实现文件
- `cpp_reborn/include/GameTypes.h` - 全局类型定义
- `cpp_reborn/include/GameObject.h` - 核心基类
- `.trae/rules/check.md` - 项目规则文档（重要！）

## 重要技术细节

### 1. 坐标系统差异
Pascal和C++使用不同的坐标系统，已做转换：
- 场景移动：X/Y需要交换
- 世界地图方向编码与场景方向编码不同

### 2. 颜色格式
使用调色板索引格式：`0xIIFFFFFF`，其中II是调色板索引：
```cpp
uint32_t color = (paletteIndex << 24) | 0xFFFFFF;
```

### 3. 阴影文字
阴影偏移只在水平方向：`(x + 1, y)`，不是右下角。

### 4. 数据类型映射
| Pascal | C++ |
|--------|-----|
| smallint | int16_t |
| integer | int32_t |
| word | uint16_t |
| byte | uint8_t |

### 5. 起始场景
游戏从场景0（客栈）开始，坐标(38, 38)。

## 开发注意事项

1. **二进制兼容性优先**：所有游戏实体必须保持与原版数据文件的兼容性
2. **参照Pascal源码**：实现逻辑时应先分析`kys_*.pas`文件
3. **不要使用g++**：被公司安全软件阻止，使用cmake --build
4. **遵循check.md规则**：包含方向映射、坐标系统等重要信息

## 常用命令

```bash
# 构建（唯一构建目录：仓库根 build/）
cmake -S cpp_reborn -B build
cmake --build build --config Debug --target kys_cpp

# 运行
./build/Debug/kys_cpp.exe
```
